# 자료 공개 원칙

이 디렉터리는 공개 자료의 출처와 작성 범위를 기록합니다.

- 개인 작성 코드와 업체 제공 코드를 구분합니다.
- 원본 로그 대신 익명화한 예시와 집계 결과를 사용합니다.
- 보드별 내부 인터페이스는 공개 가능한 범위에서 일반화합니다.
- 플랫폼, 제품과 업체를 직접 식별할 수 있는 이름은 일반화합니다.
- 확인하지 않은 결과를 PASS로 확대하지 않습니다.
- 교육용 개인 프로젝트이며 기업의 공식 제품 평가가 아님을 명시합니다.
- 정량값은 제한된 시험 조건의 관측 결과로만 설명하며 제품 전체의 결함이나 품질 판정으로 확대하지 않습니다.
